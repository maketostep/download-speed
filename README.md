# download-speed

Консольный скрипт на Node.js для замера скорости скачивания. Скрипт 10 раз подряд скачивает файл по адресу, который вы передали, и печатает среднее время запроса, общий объём и скорость.

## Требования

Node.js 20 или новее. Зависимостей нет, `npm install` запускать не нужно.

## Запуск

```bash
git clone https://github.com/maketostep/download-speed.git
cd download-speed
node speedtest.js https://speedtest.selectel.ru/10MB
```

Подойдёт любой адрес http или https: тяжёлая картинка, тестовый файл хостинга, архив.

## Единицы

| Величина | Единица | Перевод |
|---|---|---|
| Время запроса | ms, миллисекунды | |
| Объём | MB, мегабайты | 1 MB = 1 000 000 байт |
| Скорость | Mbit/s, мегабиты в секунду | 1 Mbit = 1 000 000 бит |

Скорость я вывожу в мегабитах: в них провайдеры пишут тарифы и показывают результат speedtest-сервисы, так что цифру можно сразу сравнить с тарифом.

## Как скрипт считает

- Отправляет 10 GET-запросов по очереди. Следующий запрос уходит после того, как скрипт дочитал предыдущий ответ до последнего байта.
- Время запроса идёт от отправки до конца тела ответа. В первый запрос входят DNS и TLS-рукопожатие, остальные переиспользуют соединение (keep-alive), поэтому первый замер обычно дольше.
- Среднее время равно сумме времён, делённой на 10.
- Скорость равна общему объёму в битах, делённому на суммарное время всех запросов.
- Скрипт шлёт `Accept-Encoding: identity` и просит сервер не сжимать ответ, чтобы объём в отчёте совпал с трафиком. Скрипт считает байты тела после распаковки: если сервер проигнорирует заголовок и сожмёт ответ, объём и скорость выйдут выше реальных. Картинки и бинарные файлы серверы и так не сжимают.
- Если сервер вернул код не из 2xx или запрос упал на сети (DNS, отказ соединения), скрипт печатает номер запроса и причину и завершается с кодом 1. Без адреса или с некорректным адресом он печатает подсказку по запуску и тоже выходит с кодом 1.

## Тесты

```bash
npm test
```

Тесты поднимают локальный HTTP-сервер и проверяют две вещи: скрипт делает 10 замеров и насчитывает ровно 1 000 000 байт, а на ответе 404 останавливается с ошибкой.
